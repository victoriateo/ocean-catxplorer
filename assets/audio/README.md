# Recordings

Drop a sound file here, named after the sound it replaces, and the site uses it instead of the
code-made stand-in. Use `.mp3`, `.m4a`, `.ogg` or `.wav`. Anything missing keeps its stand-in.

| File name | Where it plays |
|---|---|
| `ambient-surface` | loop: sea and waves above water |
| `ambient-deep` | loop: underwater ambience (the site muffles it more as you go deeper) |
| `splash` | Catto hits the water |
| `bubble` | quiet, random bubble pops underwater |
| `boop` | bouncing off a jellyfish |
| `wheee` | hitching a ride on the turtle |
| `whoosh` | the sardine shoal wraps round Catto |
| `snap` | the anglerfish snaps |
| `ink` | the squid squirts ink |
| `shark` | the shark passes (low swell) |
| `chest` | the chest opens (chime) |
| `coins` | coin jingle |
| `ascend` | the ride back up (rising whoosh) |
| `meow` | clicking the sardine tin |
| `rumble` | soft, distant rumbles in the deep |

Loops should be seamless (start and end match) and 20–60 seconds long. Keep effects short and
trimmed, with no silence at the start.
